# Halcyon

> Halcyon (Halcyon Tech, Inc.) is a purpose-built, adaptive anti-ransomware and cyber-resilience platform. A lightweight endpoint agent detects and disrupts ransomware across the full attack lifecycle (pre-execution, encryption, data exfiltration), with encryption-key recovery, a managed 24/7 Ransomware Operations Center (ROC), and a ransomware recovery warranty. Halcyon exposes a REST API for device/asset data and a universal API for streaming alerts into SIEM, SOAR, and XDR platforms. Backed by Bain Capital Ventures and Obvious Ventures.

- Integrations: Splunk, Microsoft Sentinel, Google SecOps, Sumo Logic, Exabeam (SIEM/SOAR/XDR); Veeam, Cohesity, Acronis, Commvault (backup); Microsoft Defender, CrowdStrike Falcon, SentinelOne, Palo Alto Cortex XDR (EDR)
